# LM723 Power Supply

So this is a linear power supply based on the LM723 IC. It utilizes the LM723 chip and a TIP35C transistor for voltage regulation. The TIP35 transistor generates significant heat, so it requires effective cooling — specifically a heatsink and ideally a fan, though a large heatsink alone may suffice.

Resistor RV1 is used to adjust the output voltage.

The current limiter engages when the output current exceeds by approximately 3A.

An N11BW enclosure was used for the power supply - custom front and rear panels were designed for it, and the corresponding stl files are available in the repository.

---

Перед вами - лінійний блок живлення на мікросхемі LM723. Він використовує мікросхему LM723 та транзистор TIP35C для стабілізації напруги. Транзистор TIP35 буде доволі сильно грітись, тому він потребує гарне охолодження - радіатор, та в ідеалі вентилятор, але можна обійтись і просто великим радіатором.

Резистор RV1 використовується для підлаштування вихідної напруги.

Після приблизно 3А струму на виході - спрацьовує обмежувач струму.

В якості корпусу для блоку живлення був використаний корпус N11BW, для якого були спроєктовані передня та задня панелі - їх stl файли також знаходяться в репозиторії.
